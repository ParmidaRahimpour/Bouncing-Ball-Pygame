# Bouncing Ball Game 🎮

A simple bouncing ball game built with Python and Pygame.

## Features

* Bouncing ball
* Wall collision
* Paddle controlled by keyboard
* Score system
* Ball color changes after collisions
* Ball stays inside the game window

## Controls

* **Left Arrow (←):** Move the paddle left
* **Right Arrow (→):** Move the paddle right

## Technologies

* Python
* Pygame

## How to Run

Install Pygame:

```bash
pip install pygame
```

Run the game:

```bash
python main.py
```
